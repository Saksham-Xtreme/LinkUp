# 📄 Router Pages Module

This directory contains key views mapped to application routing points.

## 📄 Files
* **[landing.jsx](file:///Users/sakshamtripathi/Desktop/Video-Confrencing/linkup-frontend/src/pages/landing.jsx):** The marketing lander, describing features and directing users to login or join meetings.
* **[authentication.jsx](file:///Users/sakshamtripathi/Desktop/Video-Confrencing/linkup-frontend/src/pages/authentication.jsx):** Renders register and login tab interfaces to handle email credentials or trigger Google SSO onboarding.
* **[home.jsx](file:///Users/sakshamtripathi/Desktop/Video-Confrencing/linkup-frontend/src/pages/home.jsx):** The post-login dashboard layout containing forms to start new meetings, join active meetings with a room code, and view past user history records.
* **[VideoMeet.jsx](file:///Users/sakshamtripathi/Desktop/Video-Confrencing/linkup-frontend/src/pages/VideoMeet.jsx):** The core WebRTC video meeting page. Integrates with the signaling backend, manages media streams, and controls local video/audio toggles and screensharing.
