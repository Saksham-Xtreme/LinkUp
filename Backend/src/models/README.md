# 🗄️ Database Models Module

This directory contains Mongoose schemas defining the structure of collections stored in MongoDB.

## 📄 Files
* **[meeting.model.js](file:///Users/sakshamtripathi/Desktop/Video-Confrencing/Backend/src/models/meeting.model.js):** Defines the structure of meeting records, including room codes, user associations, and timestamps.
* **[users.model.js](file:///Users/sakshamtripathi/Desktop/Video-Confrencing/Backend/src/models/users.model.js):** Outlines the user profile schema, specifying storage constraints for fields like Google OAuth IDs, passwords, emails, and usernames.
